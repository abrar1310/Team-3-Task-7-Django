# Team-3-Task-7-Django
Digital Library Management System - DiLiMS

## Description
DiLiMS is a library management system built with Django and Django REST Framework.  
It handles **books, authors, borrowing records**, and includes **user authentication and permissions** using JWT.

## Features
- User registration and login with JWT
- User profiles
- Book management (CRUD for admin users)
- Borrowing and returning books
- Role-based permissions for users
